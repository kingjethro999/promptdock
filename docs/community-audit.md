# PromptDock Community Architecture Audit

| Question                  | Current Implementation                                                                                                                           | Community Plan                                                                                                                  |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------- |
| **1. Router & Server**    | Next.js 16 App Router (`src/app/`). `/p/[publicId]` in `src/app/p/[publicId]/page.tsx`, `/invite/[code]` in `src/app/invite/[code]/page.tsx`.    | Reuse App Router for `/community` and `/[username]`.                                                                            |
| **2. DB & Query Layer**   | PostgreSQL via `pg.Pool` in `src/database.js`. Migrations in `src/schema.js`. `users.id` is `uuid`, `prompts.id` is `uuid`.                      | Extend `schema.js` with idempotent DDL and indexes; queries via `pool.query`.                                                   |
| **3. Users & Identity**   | `users` has `id uuid`, `email text`, `username text`. Created in `src/auth.js` (`register` & `firebaseLogin`). No avatar/bio yet.                | Extend `users` with `display_name`, `avatar_url`, `banner_url`, `bio`, `community_audience`.                                    |
| **4. Prompts & Sharing**  | `prompts.name` (title), `prompts.data` (jsonb task/data), `prompts.tags` (text[]). "Public" = link-only via `public_id uuid`. Hard delete today. | Extend `prompts` with `owner_id`, `visibility`, `listed_in_community`, `listed_at`, `origin`, `source_prompt_id`, `deleted_at`. |
| **5. Creation & Remix**   | `putPrompt()` and `duplicatePrompt()` in `src/database.js`. Editor at `/workspace` loads via `usePromptBuilderStore`.                            | Add `savePrompt()` and remix loader via `/workspace?remix=[publicId]`.                                                          |
| **6. Auth & Viewer**      | `session()` in `src/lib/server/session.ts` returns `{ user, admin } \| null`. Login return URL via `?next=`.                                     | Use `session()` for viewer detection and `safeReturnTo()` on login redirects.                                                   |
| **7. Shell Navigation**   | `WorkspaceShell` (`src/components/workspace/WorkspaceShell.tsx`) with `WorkspaceSidebar.tsx`. Landing nav in `LandingHeader.tsx`.                | Add Community to `WorkspaceSidebar` nav (before Settings) and landing menu.                                                     |
| **8. Uploads**            | No previous provider. Env vars: `CLOUDINARY_API_KEY`, `CLOUDINARY_CLOUD_NAME`, `CLOUDINARY_SECRET`, `CLOUDINARY_UPLOAD_PRESET`.                  | Cloudinary signed direct upload API in `/api/profile/assets/sign`.                                                              |
| **9. Utilities & Tokens** | Rate limiter in `src/rate-limit.js`. Toast via `.toast` / `react-live-toast`. `node:test` + Playwright. Tokens in `styles.css`.                  | Reuse rate limiter, toast pattern, CSS variables, and Playwright harness.                                                       |
| **10. Social Previews**   | Dynamic OG via `next/og` (`/api/og/default`, `/api/og/p/[publicId]`, `/api/og/invite/[code]`, `Card.tsx`).                                       | Add `/api/og/u/[username]` using existing `Card.tsx` layout and fonts.                                                          |

### Component Reuse Strategy

- **Reuse As-Is**: `src/lib/server/session.ts`, `src/lib/og/Card.tsx`, `src/lib/site.ts`, `src/styles/shared/styles.css`, `src/rate-limit.js`.
- **Extend**: `src/schema.js` (DDL & indices), `src/database.js` (community queries), `src/components/workspace/WorkspaceSidebar.tsx`, `src/components/landing/LandingHeader.tsx`, `src/app/p/[publicId]/page.tsx`.
- **Create**: `src/lib/community/access.ts`, `src/lib/community/username.ts`, `src/lib/community/types.ts`, `src/lib/community/queries.ts`, `src/lib/community/save.ts`, `src/lib/community/uploads.ts`, `src/app/community/`, `src/app/[username]/`, `src/app/api/community/`, `src/app/api/profile/`, `src/app/api/og/u/[username]/`.
